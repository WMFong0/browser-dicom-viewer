The image stays with you.

Selected files are decoded inside this browser tab. There is no upload, account, analytics layer, or persistent storage.

No DICOM file or extracted patient data is sent by the application. Only the viewer libraries and font are downloaded when the page opens.

Use Clear session at any time. Refreshing or closing the tab also releases the selected files and decoded image cache.

Common DICOM image transfer syntaxes supported by the browser decoder. Unsupported or malformed files fail locally and are never uploaded.
