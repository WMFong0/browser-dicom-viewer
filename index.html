Privacy architecture

Your scan never leaves your device.

Files are decoded temporarily in browser memory. Closing or refreshing the page releases the session.

01

No uploads

DICOM files are read with the browser File API and are never sent to this website.

02

No persistence

The viewer does not use cookies, localStorage, IndexedDB, analytics, or a database.

03

Explicit cleanup

Clear the session at any time to purge the active series and cached decoded images.
